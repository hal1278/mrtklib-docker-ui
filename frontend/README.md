# Frontend

This directory contains the MRTKLIB Web UI frontend built with React 19,
TypeScript, Vite, and Mantine 8.

## Commands

```bash
npm ci
npm run dev
npm run build
npm run lint
```

The Vite dev server listens on `http://localhost:5173` and proxies
`/api` and `/socket.io` to the backend at `http://localhost:8000`.

For repository-level workflow and runtime notes, see the root
[`README.md`](../README.md).
